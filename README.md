# Smart Campus Attendance & Study Planner

Mini project for **TY BTech Information Technology** (`2026–27`), **Team Alpha**, under faculty guide **Mahesh Vhatkar**.

## Overview
A lightweight web-based mini project designed to help students and faculty track attendance, manage study and project milestones, and review progress summaries.

## Features Included
- **Student Attendance Tracker:** View team members (`2024BIT001`–`2024BIT004`) and toggle attendance status between Present and Absent.
- **Study & Project Milestone Board:** Add new project milestones or study tasks and track completion status.
- **Faculty Progress Review Summary:** Displays live counts of present students and total milestones.
